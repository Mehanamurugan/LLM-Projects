# Enisteen AI Interview & Career Coach

## Overview

Enisteen AI Interview & Career Coach is a Large Language Model (LLM) powered application developed using Groq, LangChain, Speech Recognition, and Text-to-Speech technologies.

The application helps students and job seekers prepare for interviews, generate learning roadmaps, receive career guidance, and interact with an AI assistant using both text and voice.

---

## Features

### Career Guidance

Provides personalized guidance for:

* Data Science
* Machine Learning
* Deep Learning
* NLP
* LLM
* Career Planning
* Skill Development

### Roadmap Generator

Generates detailed learning roadmaps including:

* Skills to Learn
* Tools and Technologies
* Recommended Projects
* Learning Sequence
* Interview Preparation Tips

### Mock Interview

* Generates interview questions
* Evaluates user answers
* Provides feedback and improvement suggestions

### Voice Assistant

* Speech-to-Text
* LLM Response Generation
* Text-to-Speech Output

### Voice Mock Interview

* Voice-based interview questions
* Voice answer collection
* Automated answer evaluation

### Chat History Storage

Stores user interactions in JSON format for future reference.

## Workflow

1. User selects a feature from the main menu.
2. User enters text or voice input.
3. Input is processed using Groq LLM.
4. AI generates a response.
5. Response is displayed and optionally converted to speech.
6. Conversations are stored in JSON format.
